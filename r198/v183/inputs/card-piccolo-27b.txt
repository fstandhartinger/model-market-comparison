Piccolo is a local decision model for structured judgments, including tool review and context compaction in QwenPaw. This repository contains the complete Hugging Face checkpoint of Piccolo-27B selected on October 28, 2026, including the auxiliary tensors referenced by its weight index.

- Project: [agentscope-ai/Piccolo](https://github.com/agentscope-ai/Piccolo)
- Playground: [Decision Playground](https://decisionplayground.agentscope.io/)
- Base model: [Qwen3.5-27B](https://huggingface.co/Qwen/Qwen3.5-27B)
- License: [Apache 2.0](LICENSE), following the QwenPaw-Flash model-card convention and the checkpoint's bundled license.

## Inference contract

Piccolo uses **bidirectional prompt attention in full-attention layers**, while linear-attention layers retain their original computation. Inputs use the **flex_twice** layout with thinking disabled. Each question is evaluated as a complete prompt, and candidate probabilities are obtained from the single-token answer logits at temperature 1.0. No explanatory text or probability JSON is generated by the model.

Do not run these weights as an ordinary causal chat model: a successful load is not evidence that the attention mask and decision probabilities are correct. Prefix-cache reuse and chunked prefill require compatibility with the bidirectional prompt; the provided reference uses neither. The repeated layout is used only when the complete request's one-pass token budget is at most 3,000 and each repeated row fits the context limit.

## Reference inference

The repository includes `piccolo_inference.py` and `piccolo_layout.py`. Install the dependencies in `requirements.txt` (including Accelerate), then download this repository with the Hugging Face CLI:

```bash
hf download agentscope-ai/Piccolo-27B --local-dir Piccolo-27B
python Piccolo-27B/piccolo_inference.py --model Piccolo-27B --request request.json --device cuda:0
```

Example `request.json`:

```json
{
  "state": "The user asked to list files in the current directory.",
  "questions": {
    "destructive": {
      "type": "noul",
      "instructions": "Could this operation delete or overwrite existing user data?"
    }
  }
}
```

## QwenPaw

Follow the [pinned local setup guide](https://github.com/Xinji-Mai/QwenPaw/blob/beea37749185553a6897e546eae6b7954717da5b/docs/local-piccolo.md). BF16 GGUF is also available in [27B BF16](https://huggingface.co/agentscope-ai/Piccolo-27B-BF16). The PR remains draft and requires its companion runtime adaptation.

Use the existing local model download and Start controls, then select Piccolo as the default decision model. Enable Decision Model Mode for tool review and decision-model compaction through their existing settings. Starting a model does not enable either feature.

The local GGUF path requires a llama.cpp runtime with Piccolo's input layout, bidirectional prompt handling, and native `/v1/systemone` candidate scoring. The integration is available in [QwenPaw Draft PR #8463](https://github.com/agentscope-ai/QwenPaw/pull/8463); stock causal Chat Completions and unadapted Ollama are not equivalent implementations. GGUF artifacts use the separate [27B Q8_0 repository](https://huggingface.co/agentscope-ai/Piccolo-27B-Q8_0), following QwenPaw-Flash's quantization suffix convention. Q4_K_M is also published in the separate [27B Q4_K_M repository](https://huggingface.co/agentscope-ai/Piccolo-27B-Q4_K_M); its model card records the expanded synthetic numerical regression results and limitations.

## Evaluation and limitations

The following benchmark results correspond to these published full checkpoint weights.

| HarnessJevBench Hard ↑ | DataJevBench ↑ | JevBench Public ↑ | Decision Index Public ↑ |
| ---: | ---: | ---: | ---: |
| 82.03% | 82.40% | 92.21% | 68.29 |

See the [release evaluation and source snapshots](https://github.com/agentscope-ai/Piccolo/blob/0d1b3d4544766a55d137b979e8c87141bf182059/evaluation/README.md). This model-card update did not rerun benchmark inference. Quantized artifacts have separate numerical regressions; these are not remeasured quantized benchmark scores. No calibrated approval thresholds are claimed. Candidate probabilities describe the model distribution and are not an empirical guarantee of correctness. Tool review should retain human-confirmation fallback, and context compaction should retain a recovery path for source content. Resource requirements, quantization error, latency, and task quality depend on the artifact and runtime and require separate validation.
