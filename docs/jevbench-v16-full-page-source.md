# Complete page source candidate, not an adopted release

New `JevBenchV16PublicPage` is the server wrapper around the pure `loadJevV16Page` contract, and `JevBenchV16ReleasePage` renders Capability → synchronized cost/latency plot (2D bubbles and rotatable 3D projection) → Composite/WhatIf → both comparison radars and language view → collapsed full catalogue/grid → method/rotation/reference → revision history. It has no route, file-path reader, scorer callback, network, ambient data import or v15 cast. Existing v155 route and prior source are unchanged.

The server parent must supply actual adopted PUBLIC stored aggregate bytes and independently authenticated expected hashes for the five existing projection inputs, page manifest, profiles, and actual as-of day. The loader checks exact stored-byte hashes before strict duplicate-preserving JSON parsing; production defaults reject fixtures. Structural hashes are not source/runtime/release authority. No current data was read by this producer. The new tests explicitly mark fixture=true and opt in only for synthetic assembly/SSR.

A page manifest is required: `kind=jevbench-v16-page`, schema1, generated_on, exact projection_hashes, full116 expected_catalogue_keys, category_profiles_sha256, six or more actual method paragraphs, rotation item/reserve counts/use retirement/API cadence disclosure, original scorer hash and precomputed WhatIf scenarios, official scenario ID and genuine revision date/source entries. All stored scenario scores cover exactly every ranked model, have the same scorer source, and the official scenario equals stored Composite. The weight sliders select only stored exact combinations; unscored combinations leave the previous scenario with an explicit unavailable notice. No old harmonic formula, interpolation or estimated WhatIf score exists in this component.

Each ranked model requires a profile bound to exact version/pin/main date and original profile date/revision/metric/scope/source hash. Current cells must exactly equal the existing projection's actual topic/usecase cells. Current A300+P300 and S1200+P300 stay UNEQUATED; carry retains its original metric and cohort in separately drawn panels. All expected profile keys are mandatory, so dropping forty older models fails. Current and historical series are not overlaid. The language view uses separately dated original public/sealed cells, count/non-ok/status and carried original base measurement, outside Composite. Missing/low-n values are omitted and the accessible table retains explicit counts/status.

Real blocking producer contracts remain:

* The accepted projection currently rejects ranked carry in its current-only categoryProfile/diagnostics path. This new page **does not fix or silently bypass it**. An independently reviewed explicit carry projection/profile bridge and actual old per-model dates/provenance are necessary before the complete ranked catalogue can pass this server wrapper. The page's pure assembly can represent admitted carry profiles, but that is not evidence of available authentic carry artifacts.
* Root's official scorer→projection adapter must emit exact existing projection/bindings/origin joins and actual category/language artifacts. Precomputed WhatIf grids must come from actual admitted official scorer source, rather than UI weights math. Unknown output combinations remain unavailable.
* Projection currently has no model-size/context metadata contract; the table does not infer those fields from names. Full additional metadata columns require reviewed scalar origins if the final page requires them. Existing actual axes, cost roles, median/p95, supports, author/repo/licence/date/version/pin and eligibility are rendered.
* Actual method text/counts/rotation and version history must come from final public admission; page source numbers do not create an exposure/cadence waiver. Actual category coverage, multilingual floors, top-five comparison, final independent review and preview GO/publication remain separate.

Cost bars preserve served, developer API list-price scenario and striped base-reference roles. Scenario prices cannot replace actual GPU median or cost admission; missing median never uses Speed. Current/carry historical prices retain method/request-length disclosures. The common filters/caps drive headline and bubble plotting; Composite uses its stored official/scenario scores independently. All116 catalogue rows, including unranked/unmeasured, remain in the grid.
