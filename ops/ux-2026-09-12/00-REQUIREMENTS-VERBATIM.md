I also have an idea: we could add a Benchmaxxing tab in the Advanced section of Benchmark Heaven and the idea is this: We assume a model is benchmaxxed if it scores very well on some of the benchmarks but very bad on others. The assumption basically is the training data is either polluted with the test set of the good-scoring benchmarks, or the training team has explicitly nudged the model to become very good at that typical type of task that certain benchmarks consist of so that when the model is released they score super well on these benchmarks and look like a big success, but if that was done in the training, instead of just trying to achive a very general set of capabilities and intelligence it would probably show up as the model performing very bad in certain benchmarks, e.g. community owned or niche ones that weren't part of this explicit nudging/pollution of the training data. so what I'd like so see is some mechanism that tries to identify these cases. find a smart way to do that. one naive way I can think of is: if you take a set of models for which we have scores from pretty much all of the different benchmarks+evals, we could take one of these benchmarks and train a xgboost/lightgbm model on all the other benchmarks scores, that would estimate/predict the score of this excluded benchmark. and then if we see that this prediction is matching very well the actual value, we assume it's not a benchmaxxed model, and if the difference is very bad, it's a sign there is a lot of benchmaxxing going on. and of course this single delta value is not enough, we'd have to repeat the process for all the benchmarks/evals and then look at all these deltas (I don't know, maybe summing these delta values up or some quadratic mean or so) in order to identify the total benchmaxxing thing.
