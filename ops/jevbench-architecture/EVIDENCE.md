# JevBench architecture evidence

Checked UTC: 2026-10-05T19:53:50Z

This presentation-only mapping covers every top-level system row in all JevBench JSON artifacts, including dated carry, all multimodal previews and excluded historical runs. ImageJevBench contains the union of the checked preview ranking keys. Category labels and per-item source logs are not system rows. No score, rank, item, model runtime or artifact was changed.

Weights availability governs the architecture axis; serving through an API does not hide publicly released decoder weights. Hosted services with no public evaluated checkpoint are closed-api. TypeSafe Jev alone is jev-reference. Vision towers, learned decision heads, option-order averaging and mixture-of-experts layers are components of a single backbone, not independent multi-model systems. No evaluated router/cascade/ensemble was established, so system has zero entries.

## Cases with indirect or limited evidence

- `bonsai_2_27b_pq2_0`: Author README confirms local generative inference; upstream identity is undisclosed, so the broad decoder class is used without a base-model claim.
- `evalengine-decision-4b`: No standalone config in the adapter repo; author card identifies the Qwen3.5-4B LoRA. An adapter is still a decoder.
- `gliner2`: Author README documents the encoder family; there is no single config corresponding to the project repository.
- `jeff`: Author README and GLiFormer model card establish a DeBERTa encoder with a task head; an RNN task head is not a multi-model pipeline.
- `needle-3 / needle-3-tools`: Custom architecture documented in the README rather than a Transformers config; token grammar, language generation and causal attention establish the decoder class. Optional speech functionality is not part of this text evaluation.
- `mirror`: The former project repository is unavailable. The artifact identifies a DeBERTa-v3-large span scorer, whose public config verifies the encoder architecture.
- `jevision`: Existing cited config and artifact establish Qwen3.5-0.8B-Base; no separate evaluated-to-base model card was available.
- `visual_jev_generic_baseline`: Historical artifact names a zero-shot Qwen3.5-4B baseline; current author README describes a different released adapter, so only the artifact plus base config is used. Decoder class is conservative; no derivation badge is inferred.
- `surogate-rune-26b-a4b-v3-rtxpro6000-a2 / surogate_rune_26b_v3`: Existing artifact/base disclosure links the evaluated variants to Gemma-4-26B-A4B. The base config establishes decoder architecture; no author card was available in the checked sources.
- `deepseek-flash / qwen3.8-27b`: Both publish decoder weights. Measurement through a hosted API is a separate axis and does not turn public weights into closed weights. Artifact-to-config lineage evidence is recorded.
- `instinct / instinct-dual-4b / jevact`: Hosted artifacts mark evaluated implementations as closed with no immutable public evaluated checkpoint. Closed-api is conservative even when an upstream family is disclosed; the endpoint itself does not verify publicly downloadable evaluated weights.
- `laya / laya-multilingual / laya-typed-decisions`: Current provider docs also describe an optional multilingual router. Each artifact evaluates one fixed English, multilingual or typed-decisions checkpoint, so these entries remain encoders rather than systems.
